Как редактировать

Весь маршрут хранится в одном блоке данных в конце файла index.html (ищите const TRIP, PLACES, DAYS).

  • PLACES — каталог всех мест с полями: район, категория, часы работы, станция, нужна ли бронь, приоритет.
  • DAYS — план по дням; пункты ссылаются на место через placeId, плюс можно добавить еду/переезд/отдых.
  • Отметки «посещено» сохраняются в браузере (localStorage) — у каждого устройства свои.
  • Кнопка «В картах» открывает Google Maps по координатам или названию.
